# ex-day

### いつもの一日に、ちょっとした発見を。

ex-dayは、**場所・時間・人の興味をつなぎ、普段なら通り過ぎてしまう「何か」と出会うためのプロジェクト**です。

## 💭 きっかけは、身近な場所への疑問でした

自分が育った街にある、東急東横線の綱島駅。

現在は高架上にある駅ですが、昔の写真を見ると、かつては地上を走っていたことを知りました。

そこで、ふと疑問が浮かびました。

> すぐ近くには鶴見川がある。  
> 今の堤防はかなり高い。  
> 地上を走っていた当時の鉄道は、どうやって川を渡っていたんだろう？

調べてみると、街の姿、川、鉄道、土地の高さなど、普段何気なく見ていたものにも歴史があることに気づきます。

そして、興味を持つ対象は大きな歴史だけではありません。

たとえば「青柳」という貝。

現在の街の姿からはなかなか想像できませんが、かつて鶴見周辺でも採れていたという話があります。

さらに、地元の人の昔話を聞いていると、

> 採れた青柳を干して、子供のおやつにしていた家庭もあった。

そんな話が出てきます。

「昔、この場所で何があったのか」だけではなく、

**「ここで暮らしていた人たちは、どんな生活をしていたんだろう？」**

そんな身近な記憶も、場所と結びつけて残せたら面白い。

一方、出張先では、

> 「仕事は終わったけど、帰りの新幹線まで少し時間がある。  
> せっかくここまで来たのだから、何か面白いものはないだろうか？」

と思うことがあります。

一見すると別々の話ですが、どれも共通していました。

**「今いる場所」と「少しの時間」と「ちょっとした興味」があれば、いつもの一日が少し面白くなるのではないか。**

そこから **ex-day** のアイデアが始まりました。

## 🗺️ 情報を探すだけではなく、疑問も共有したい

すべての疑問に、最初から答えがあるとは限りません。

古い写真を見つけて、

> 「この場所、今はどうなっているんだろう？」

街を歩いていて、

> 「この建物の入口だけ、なぜ道路より高いんだろう？」

そんな疑問そのものを投稿できても面白いと考えています。

その地域を昔から知っている人、歴史に詳しい人、たまたま資料を持っている人。

それぞれの知識がつながれば、一人では分からなかった街の姿が見えてくるかもしれません。

## 🚄 そして、寄り道へ

ex-dayで扱いたいのは歴史だけではありません。

たとえば出張帰り。

「今日はあと3時間くらい余裕がある」

そんなときに、

- 今いる場所
- 帰る方向
- 使える時間
- 興味のあること

から、

**「だったら、ちょっとここに寄ってみませんか？」**

と提案できる。

歴史、地域のイベント、旬の食べ物、景色、お店。

目的地へ最短距離で移動するためのサービスではなく、**余った時間をちょっと面白くするサービス**を目指しています。

## 🍻 知ることは、人との会話にもつながる

地域のことを知っていると、それ自体がちょっとした会話のきっかけになります。

旅先や仕事先、場合によってはお酒の席でたまたま隣になった人と、

> 「昔、この辺って○○だったらしいですね」

なんて話から、その土地の昔話に花が咲くこともあります。

そして、そんな会話の中から、

**検索してもなかなか出てこない、その土地で暮らした人だからこそ知っている話が出てくることもあります。**

ネットで情報を読んで終わりではなく、

**知ったことが、実際の場所や人との新しいつながりを作る。**

そんな体験もex-dayが作れたら面白いと思っています。

## 🚧 現在の ex-day

ex-dayは現在、アイデアを要求・機能へ落とし込みながら、最初のプロトタイプ開発に向けて具体化を進めています。

企画だけで終わらせず、**考えたこと、迷ったこと、技術的な判断、実際に作ったものまで、できるだけオープンにしていく**予定です。

現在は、代表的な利用シーンを整理しながら、要求・画面・データ・アーキテクチャなどを少しずつ具体化しています。

## 🌱 まだ、始まったばかりです

ex-dayは現在、アイデアを具体化しながらプロトタイプを作り始めている段階です。

完成されたサービスを公開するためだけのプロジェクトではなく、

**「こんなのがあったら面白い」から、実際に使えるものになるまでの過程そのものをオープンにしていきたい**と考えています。

エンジニアだけでなく、

- 地域の歴史が好きな人
- 古い写真や資料を持っている人
- 地域の昔のことを知っている人
- 地域で活動している人
- イベントを開催している人
- 面白い場所や食べ物を知っている人
- 一緒にサービスを考えてみたい人

いろいろな人が関われるプロジェクトにしていきたいと思っています。

**いつもの一日に、ちょっとした発見を。**

それが ex-day です。
